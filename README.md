# MCP Math Manim Server

An MCP server built with FastMCP that provides calculator, expense management, and Manim animation tools.

## Features

- Mathematical calculations
- Addition
- Subtraction
- Multiplication
- Division
- Power
- Modulus
- Expense management
- Add expenses
- List expenses
- Expense summaries
- Manim animations
- Rotating triangle animation
- Rotating square animation
- MCP tool integration

## Technology Stack

- Python
- FastMCP
- MCP
- Manim Community Edition
- uv
- SQLite
- Python subprocess
